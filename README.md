# Offline Safety Checklist for Warehouse Crew

A lightweight, dependency-free safety checklist built with vanilla HTML, CSS, and JavaScript.

## Run

```bash
npm start
```

Open `http://localhost:4173`.

## Test

```bash
npm test
```

Submissions are sanitized and saved locally in browser storage. The interface includes search, empty states, loading feedback, inline validation, keyboard navigation, ARIA labels, and analytics console logging.
